# ife-obi

My personal portfolio, live at https://ife-obi.vercel.app/. A single-page site that brings together my projects, experience, skills and certificates, with a contact section and my social links.

**Live site:** https://ife-obi.vercel.app/

## Built with

- Next.js 16 and React 19, with TypeScript
- Tailwind CSS 4, shadcn/ui and Base UI components
- lucide-react icons
- Vercel Analytics
- Deployed on Vercel

## Sections

Hero, About, Skills, Experience, Certificates, Projects, Contact.

## Getting started

You need Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 with your browser.

## Scripts

- pnpm build - create a production build
- pnpm start - serve the production build
